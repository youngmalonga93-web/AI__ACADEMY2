# Video Tutorial Image Prompts

These prompts are designed for AI Academy tutorial visuals that can later be animated in Meta tools, Runway, Pika, After Effects, CapCut, or similar systems. Use them as hero frames, scene plates, thumbnails, or animated explainer backgrounds.

## Global Visual Direction

Use this style block at the end of every prompt:

```text
Visual style: premium educational SaaS, cinematic but clean, realistic people and interfaces, high-trust investor-ready look, modern AI lab meets professional workspace, rich but restrained color palette, crisp readable shapes, soft volumetric light, no fake brand logos, no tiny unreadable UI text, no clutter, no distorted hands, no extra limbs, no surreal faces, 16:9 widescreen, designed for later animation with separate foreground, midground, and background depth.
```

## Animation Planning Notes

- Build every image with depth layers: foreground subject, midground workflow, background environment.
- Leave open negative space for titles, captions, progress bars, and callouts.
- Avoid tiny text inside generated UI. Add text later in editing software.
- Ask for clear motion paths: flowing data lines, cards moving through a pipeline, dashboard panels lighting up, agents passing tasks, or timelines expanding.
- Keep all third-party logos out of generated visuals unless we have explicit rights. Use generic icons or abstract tool panels.
