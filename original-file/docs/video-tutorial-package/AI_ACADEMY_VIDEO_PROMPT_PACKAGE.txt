# AI Academy Video Tutorial Prompt Package

Use this package with free AI video generation tools that accept image/SVG references, such as Pika, Luma Dream Machine free tier, Kling free credits, Haiper, or CapCut AI video. Upload the matching SVG for the module, then paste that module prompt.

Recommended settings: 16:9 widescreen, 60-90 seconds, smooth motion, tutorial/explainer style, readable text only, subtle music, professional educational voiceover.

## Modules
