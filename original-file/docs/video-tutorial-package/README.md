# AI Academy Video Tutorial Package

This package is arranged by module. Each module folder contains:

- nimation.svg - the matching SVG reference image for the module.
- ideo-generation-prompt.txt - the ready-to-paste video tutorial prompt for that SVG.

Use AI_ACADEMY_VIDEO_PROMPT_PACKAGE.txt if you want all prompts in one file.

Recommended workflow:

1. Open a free video generation tool.
2. Upload the module's nimation.svg as the visual reference.
3. Paste the matching ideo-generation-prompt.txt.
4. Generate a 16:9 video, ideally 60-90 seconds.
5. Repeat for each module.
